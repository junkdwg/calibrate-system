วางไฟล์ฟอนต์ AngsanaUPC (.ttf) ที่นี่ แล้ว build ใหม่ (docker compose up -d --build)
เพื่อให้ PDF ที่สร้างบนเซิร์ฟเวอร์ใช้ฟอนต์ AngsanaUPC จริง
ไฟล์อยู่ใน Windows: C:\Windows\Fonts  (ค้นชื่อ "AngsanaUPC" - ปกติ regular + bold)
ฟอนต์นี้มีลิขสิทธิ์ของ Microsoft: ใช้ได้เฉพาะสำเนาที่บริษัทมีสิทธิ์ใช้ และห้ามเผยแพร่ออกนอกบริษัท
(ถ้าไม่วาง ไฟล์ Excel ยังใช้ AngsanaUPC ถูกต้อง แต่ PDF จะใช้ฟอนต์สำรองแทน)
